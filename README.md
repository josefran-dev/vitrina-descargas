# Vitrina

**Tu catálogo de productos en PDF, listo para WhatsApp.**

Vitrina es una aplicación de escritorio para **Windows y Mac** donde cargas tus productos una sola vez (fotos, descripción y precio) y ella arma el catálogo por ti: con portada, estilos, precios de contado, mayoreo o a crédito (semanal, quincenal o mensual), y un botón «Pedir por WhatsApp» en cada producto. Funciona **sin internet** y tus datos se guardan en tu propia computadora.

Todas las versiones están en [Releases](https://github.com/josefran-dev/vitrina-descargas/releases).

## Instalar

**Windows:** abre el instalador. Si aparece *«Windows protegió su PC»*, toca **Más información** y luego **Ejecutar de todos modos**. Sale porque Vitrina es un programa nuevo; es seguro.

**Mac:** abre el `.dmg` y arrastra Vitrina a Aplicaciones. Si macOS no la deja abrir, ve a *Ajustes › Privacidad y seguridad* y toca **Abrir de todos modos**. Si dice que «está dañada», abre la Terminal y pega: `xattr -dr com.apple.quarantine /Applications/Vitrina.app`
